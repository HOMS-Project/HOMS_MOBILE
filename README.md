# 🚚 HOMS - Home Moving Service (Mobile App)

Welcome to the Mobile App repository for **HOMS (Home Moving Service)**! Built with React Native and Expo, this application allows users to easily book moving services, track their movers in real-time, and manage their profile on the go.

## 🚀 Technologies Used
- **Core:** React Native, Expo (SDK 55)
- **Styling:** NativeWind (Tailwind CSS for React Native)
- **Navigation:** React Navigation (Native Stack, Bottom Tabs)
- **Maps & Location:** React Native Maps, Expo Location
- **Real-time:** Socket.io Client
- **Authentication:** Expo Auth Session
- **UI Components & Utilities:** Expo Blur, Expo Image Picker, Expo Linear Gradient, React Native Reanimated
- **HTTP Client:** Axios

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- Expo Go app on your physical device OR an iOS Simulator / Android Emulator.

### Installation

1. Navigate to the mobile directory:
   ```bash
   cd HOMS_MOBILE
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Environment Variables:
   Create a `.env` file to store your API URL and other configuration keys.

### Running the App

Start the Expo development server:
```bash
npm start
```

Press `a` to run on Android, `i` to run on iOS, or scan the QR code with the Expo Go app on your physical device.

## 📁 Project Structure
- `src/` - Source code including screens, components, navigation, and state management.
- `assets/` - Images, fonts, and other static assets.
- `app.json` / `app.config.js` - Expo configuration.
- `tailwind.config.js` - NativeWind/Tailwind configuration.
